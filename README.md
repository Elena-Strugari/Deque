# Deque Implementation in C++

## Introduction
This repository contains an implementation of a **Deque (Double-ended Queue)** in **C++**. 
A Deque is a linear data structure that allows insertion and deletion of elements from both the front and the rear.

## Features
- Insert elements at both ends (front & rear)
- Delete elements from both ends
- Retrieve front and rear elements
- Check if the deque is empty or full
- Display the contents of the deque

## Technologies Used
- **C++**
- **Standard Template Library (STL)** 
- **Object-Oriented Programming (OOP) principles**
